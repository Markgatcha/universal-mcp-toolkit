⚡ Quick Start

# List all available servers
npx universal-mcp-toolkit list

# Interactive setup for Claude Desktop or Cursor
npx universal-mcp-toolkit install

# Run a server locally
npx universal-mcp-toolkit run github --transport stdio

# Or use streamable HTTP (MCP 2026-07-28 stateless)
npx universal-mcp-toolkit run github --transport streamable-http --port 3333

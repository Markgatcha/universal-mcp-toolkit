Getting Started

Set up universal-mcp-toolkit with the smallest possible path first.

stdio

Local workflows, Claude Desktop

SSE

Remote HTTP+SSE integrations

Streamable HTTP

MCP 2026-07-28 stateless, serverless

1 List Available Servers

npx universal-mcp-toolkit list

Browse the 40+ available MCP servers and find what you need.

2 Interactive Setup

npx universal-mcp-toolkit install

Interactive wizard that generates config for Claude Desktop, Cursor, or raw JSON.

3 Find Your Host Config

  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json
  • Cursor: ~/.cursor/mcp.json

4 Generate Config

npx universal-mcp-toolkit config \
  --server github,slack,filesystem \
  --target claude-desktop \
  --write ~/claude-mcp-config.json
The JSON examples use literal placeholders such as ${GITHUB_TOKEN}. Replace them with real values before pasting into your host config.

5 Validate & Run

npx universal-mcp-toolkit doctor github
npx universal-mcp-toolkit run github --transport stdio

The doctor command checks build outputs and required environment variables.

6 Streamable HTTP (MCP 2026-07-28)

npx universal-mcp-toolkit run github \
  --transport streamable-http \
  --host 0.0.0.0 \
  --port 3333
The streamable HTTP transport uses the MCP 2026-07-28 stateless protocol — each request gets its own transport instance, enabling serverless and edge deployment without session management.
